# Task 2 - Virtual Lab Setup

## Objective

The objective of this task was to create a safe and controlled environment
for practicing ethical hacking and cybersecurity concepts.

## Environment

- Host OS: macOS
- Virtualization Software: VirtualBox
- Virtual Machine: Kali Linux
- Purpose: Cybersecurity and ethical hacking practice

## Steps Performed

1. Installed the virtualization software.
2. Downloaded the Kali Linux ISO.
3. Created a new virtual machine.
4. Configured the virtual machine settings.
5. Attached the Kali Linux ISO.
6. Installed Kali Linux.
7. Started Kali Linux successfully.
8. Verified that the system was working inside the virtual machine.

## Why Use a Virtual Lab?

A virtual lab provides an isolated environment for cybersecurity practice.
It helps prevent accidental changes or attacks against the main computer
or unauthorized systems.
