## 1. Introduction

Cybersecurity means protecting computers, networks, applications and data from unauthorized access, attacks and damage.

Ethical hacking is a process where a person checks a system for security weaknesses with proper permission. The main goal of ethical hacking is to find vulnerabilites and help improve the security of the system.

An ethical hacker uses some of the same techniques that attackers use, but they do it legally and with permission from the owner of the system.

### Main objectives of ethical hacking

- Find security vulnerabilities.
- Understand how an attacker can exploit a weakness.
- Check the security of a system.
- Help fix security problems.
- Improve the overall security of the system.

---

## 2. Types of Hackers

There are different types of hackers depending on their purpose and authorization.

### White Hat Hacker

White Hat hackers are authorized security professionals who test systems to find security weaknesses.

They have permission from the owner of the system and report the vulnerabilities so they can be fixed.

**Example:**  
A company hires a penetration tester to check its website for security vulnerabilities.

### Black Hat Hacker

Black Hat hackers access systems without permission. They may steal data, damage systems or use the information for illegal purposes.

**Example:**  
An attacker gets unauthorized access to a company's database and steals customer information.

### Grey Hat Hacker

Grey Hat hackers are between White Hat and Black Hat hackers. They may find or access a vulnerability without getting proper permission first. Their intention may not always be to cause harm, but accessing a system without permission is still unauthorized.

### Difference between hackers

| White Hat | Authorized | Improve security |
| Black Hat | Unauthorized | Malicious or illegal activity |
| Grey Hat | May not have permission | Find or expose vulnerabilities |

## 3. CIA Triad

The CIA Triad is one of the basic concepts of cyber security.

CIA stands for:

- Confidentiality
- Integrity
- Availability

These three principles are used to protect information and systems.

### Confidentiality

Confidentiality means making sure that information is only available to people who are authorized to access it.

**Example:**  
A student's marks should only be accessible to the student and authorized college staff.

**Some methods used for confidentiality are:**

- Passwords
- Encryption
- Access control
- Multi-factor authentication

### Integrity

Integrity means making sure that data is correct and is not changed by an unauthorized person.

**Example:**  
An attacker should not be able to change a student's marks in a college database.

**Some methods used for integrity are:**

- Hashing
- Digital signatures
- Access control
- File monitoring

### Availability

Availability means that systems and data should be available when authorized users need them.

**Example:**  
An online banking website should be available when customers need to use their account.

**Some methods used for availability are:**

- Backups
- Redundant systems
- Disaster recovery
- System monitoring
- DDoS protection

### CIA Triad Summary

 Confidentiality = Protect information from unauthorized access. e.g Encryption
 Integrity = Protect data from unauthorized changes. e.g. Hashing
 Availability = Keep systems and data accessible. e.g. Backups

## 4. Common Cybersecurity Threats

There are many different cyber threats that can affect computer systems. Some common threats are malware, phishing and ransomware.

### Malware

Malware means malicious software that is designed to harm a computer system or perform unwanted actions.

Some examples of malware are:

- Virus
- Worm
- Trojan
- Spyware
- Keylogger

Malware can be used to:

- Steal information
- Damage files
- Monitor user activity
- Give unauthorized access
- Disrupt a system

### Phishing

Phishing is a type of social engineering attack where an attacker tries to trick a person into giving sensitive information or clicking on a harmful link.

A phishing message can pretend to be from:

- A bank
- A company
- Social media
- A friend or colleague
- A government organization

**Example:**

An attacker can send an email saying:

 "Your account will be suspended. Click here to verify your account."

The link can take the user to a fake login page where the attacker can try to steal the username and password.

### How to identify phishing

Some common signs of phishing are:

- Suspicious links
- Unknown sender
- Urgent messages
- Unexpected attachments
- Requests for passwords
- Suspicious website domains
- Spelling or grammar mistakes in messages

### Ransomware

Ransomware is a type of malware that can make files or systems inaccessible and then demands money from the victim.
